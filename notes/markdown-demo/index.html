一个小问题

给定正整数 n，求从 1 到 n 的整数之和。

例如，输入 5，结果应该是 15。

观察

我们可以逐个累加，也可以使用公式：

1+2+⋯+n=2n(n+1)​

C++ 代码

#include <iostream>

int main() {
    long long n;
    std::cin >> n;
    std::cout << n * (n + 1) / 2 << '\n';
}

如何运行

  1. 将代码保存为 main.cpp。
  2. 在终端编译并运行：
g++ main.cpp -o main
./main
  1. 输入 5，检查输出是否为 15。

复杂度与注意事项

方法时间复杂度额外空间
逐个累加O(n)O(1)
使用公式O(1)O(1)

注意乘法可能溢出：即使使用 long long，也仍然需要根据输入范围判断是否安全。
